# 创建与编辑工作流

## 创建

1. 确定文档类型和目标读者。
2. 选择 `business` 或 `compact`，在工作区编写内容 JSON。
3. 长篇说明放在段落中，表格只用于可重复比较的记录。
4. 运行 `scripts/create_docx.py`。
5. 运行结构检查器。
6. 渲染到新的页面图片目录；支持图片输入时检查每一页。
7. 修改 JSON 或执行针对性的编辑，然后重新生成或渲染。

## 编辑

1. 检查源文件并保留未修改的副本。
2. 用操作 JSON 表达精确替换和追加内容。
3. 运行 `scripts/edit_docx.py`，输入与输出使用不同路径。
4. 确认每项必需替换至少匹配一次。
5. 检查并渲染编辑后的副本。

插件资源 `sample-edit-spec` 提供最小操作文件示例。

不要为局部措辞修改重建整份文档。内置编辑器有意不修改文本框、绘图层文字和域指令；任务涉及这些结构时使用针对性的 OOXML 辅助脚本。
