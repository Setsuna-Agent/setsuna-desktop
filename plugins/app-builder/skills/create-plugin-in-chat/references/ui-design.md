# Setsuna 应用界面规范

这是生成侧栏应用的默认设计基准。用户明确指定的风格优先；已有应用只改请求涉及的部分。样式来自宿主 `shared/styles/tokens.css` 和 `renderer-ui/styles/{controls,table}.css`，以下资源已经适配沙箱，无需寻找宿主源码或导入 React 组件。

## 结构与尺度

| 项目 | 默认值与用法 |
| --- | --- |
| 字体 | `var(--setsuna-font-family)`；不加载网络字体 |
| 正文 / 控件 / 表格 | 14px / 13px / 12px；行高 1.5 / 20px / 18px |
| 页面 / 区块标题 | 20px / 14px，字重 600；一个页面一个主标题 |
| 间距 | 使用 4、8、12、16、24、32px；图标与文字 6px，同行控件 8px，组内 16px，组间与页面内边距 24px |
| 控件 | 默认高 32px；按钮水平内边距 12px，输入框 10px；同一行等高并垂直居中 |
| 圆角 | 输入框和图标按钮 8px、面板 10px、普通操作按钮胶囊形；避免层层大圆角 |
| 图标 | 16px 线性 SVG，`currentColor`，笔画 1.75；不使用 emoji 代替功能图标 |
| 表格 | 行高至少 48px，单元格内边距 8px 16px；数值右对齐并用等宽数字 |

CSS 已提供 `sa-app`、`sa-page-header`、`sa-toolbar`、`sa-stack`、`sa-grid` 等布局类，以及按钮、输入框、表格、面板和状态样式。通过少量应用级样式调整布局；不要为每个组件重新发明间距和视觉语言。

- 顶部标题和必要操作处于同一行，内容在下方。只有独立内容分组需要面板；列表和表格不逐行包成大卡片。
- 主操作使用强调色，次操作使用中性边框或透明背景。默认不加巨幅标题、渐变背景、玻璃效果、大面积色块或重阴影。
- 图标和文字使用 `inline-flex; align-items:center`，不要靠空格或逐项偏移对齐。数字徽章使用 `line-height:1`。
- 同一组采用一个 `gap`，标题、内容的默认 margin 清零；不要同时叠加父级 gap 和子级 margin。
- 窄窗口中工具栏换行、表单单列；表格保留列的阅读宽度，在自己的容器中横向滚动。flex/grid 子项设 `min-width:0`，填满视口的滚动区域还需 `min-height:0`。
- 只展示用户要求的信息和操作。不要追加欢迎词、副标题、功能介绍、统计卡、权限说明或步骤引导来填空间。图标按钮使用 `title` 和 `aria-label`。

## 主题颜色

沙箱不会继承宿主的 `--app-*` 变量或 `.sd-*` 样式。只使用宿主已传入的以下变量，基础 CSS 已直接引用它们：

| CSS 变量 | 用途 |
| --- | --- |
| `--setsuna-color-surface` / `--setsuna-color-surface-muted` | 页面、控件背景 / 表头、次级背景 |
| `--setsuna-color-text` / `--setsuna-color-text-muted` | 正文 / 次级文字 |
| `--setsuna-color-border` | 分隔线、边框 |
| `--setsuna-color-accent` / `--setsuna-color-accent-text` | 主操作、焦点 / 主操作文字 |
| `--setsuna-color-danger` / `--setsuna-color-success` / `--setsuna-color-warning` | 真实的错误、成功、警告状态 |
| `--setsuna-font-family` | 用户选择的字体栈 |

不要将页面固定成白底黑字或自己推测系统深浅模式。宿主会通过 `setsunaUI` 同步颜色和 `color-scheme`；CSS 自动响应。使用 `color-mix` 从当前变量派生悬停或选中背景。不要覆盖宿主变量；用户指定品牌色时另建应用变量。

ECharts 的画布/SVG 配置需要实际颜色字符串，不直接填 `var(...)`。在 `setsunaUI.ready` 后从 `getComputedStyle(document.documentElement)` 读取变量，在订阅回调中更新图表颜色。图表模板已提供这个过程。

## 按组件使用

- **表格**：表头浅底，分隔线轻，列标题与内容对齐；长文本有明确的截断或换行策略。排序/筛选/选择只在需求包含时实现。操作图标沿用整页尺寸与 tooltip。
- **表单**：标签在字段上方，标签与字段间距 8px、字段间距 16px；必填项按真实业务设置。错误在对应字段或提交位置按需出现；失败保留输入。默认不添加常驻说明。
- **图表**：只画用户需要的维度；一条序列优先宿主强调色，多序列使用固定顺序的配色。轻网格、12px 坐标轴标签、透明背景、明确单位；不使用 3D、阴影发光或无意义装饰。
- **交互**：保留 focus-visible，使用原生按钮和表单控件。禁用或加载时避免重复提交；hover 只改变颜色，不让控件跳动。尊重 reduced-motion。
- **状态**：真实加载、空结果、错误才显示对应状态；无数据时不伪造记录或图表。不把草稿或静态样例当已保存数据。

## 交付前核对

先核对主题变量、统一间距、窄窗溢出、键盘焦点、长标题、空/错状态和真实保存路径。没有用户要求时，不自行打开浏览器或做样式截图；静态检查不能宣称已经视觉验证。`verify_plugin` 验证数据与动作，不能代替视觉检查。
