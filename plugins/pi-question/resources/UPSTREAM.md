# 结构化提问：设计参考与许可说明

本插件使用 Setsuna 原生扩展 API 实现，交互设计参考 Pi 官方 `question.ts` 示例，固定参考提交：

- Source: <https://github.com/earendil-works/pi/blob/936aff00918de1187f085f123c2812d8f2d67745/packages/coding-agent/examples/extensions/question.ts>
- Upstream project: <https://github.com/earendil-works/pi>

Setsuna 实现：提供“选项 + 自由输入”的核心交互，通过 Setsuna 结构化输入卡片呈现，不包含 Pi 的 renderer、快捷键或命令 API。
