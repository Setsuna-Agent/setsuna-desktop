# 设计画布

点击左侧导航栏的「设计」图标进入独立工作区。在设计首页可以切换项目和目录、新建稿件，或从设计文件列表进入画布。首页递归监听当前工作区的目录变更，子目录中的新稿件会自动出现在列表中。画布顶部可切换稿件或返回首页。项目文件树打开 `*.design.json` 也会定位到该工作区，顶栏前进和后退可恢复当时选中的稿件。

画布工具条提供选择、平移、画框、矩形、椭圆、多边形、钢笔、文本、图片和图标。选择形状工具后可以拖出尺寸，也可以单击插入。属性面板未选中图层时提供手机、平板和桌面画板预设。

多边形可在属性面板设置 3 至 32 条边。钢笔点按添加直线节点，按住拖动生成贝塞尔手柄，单击起点闭合，按 Enter 完成开放路径，按 Esc 取消。保存后可通过「编辑节点」拖动锚点和手柄。整条路径完成或编辑拖动松手时提交一次。

在同一层级多选闭合形状后，右键可合并路径，或用底部形状减去上方形状。相减得到的孔洞会保留在 SVG 中。多选形状和内容后可用最上方的闭合形状创建蒙版。蒙版和内容仍可在图层树中单独编辑，也可从右键菜单移除蒙版。

图标库使用应用已安装的 Lucide 图标，按名称搜索并连续滚动浏览。选中 Lucide 图标后，可在右侧「图标」切换形状，沿用原来的尺寸、位置、填充和描边。

图标库的「导入 SVG」可选择本机文件。也可将 SVG XML 或剪贴板中的 SVG 文件用 Ctrl/Cmd+V 直接贴到画布。导入支持基础形状、路径、变换、纯色填充和描边。多色 SVG 按路径保留各自的外观，可在图层树选中子图层修改。带渐变、蒙版、滤镜或文字的文件需先转为基础矢量形状。

拖动空白区域框选，Shift 单击增减选区。图层可批量移动、复制、对齐、等距分布、成组和解组。拖动选框手柄可调整尺寸和旋转。拖动自由布局图层时会对齐附近图层的边缘和中心，按 Alt 可临时关闭吸附。图层树支持折叠、拖动排序、跨画框移动、隐藏和锁定。自由图层按前后叠放展示，弹性布局的子图层按排列顺序展示。从图层树拖到画布时，图层会跟随指针，目标弹性布局会实时预留插入位置。松手保存一次，按 Esc 取消并恢复原布局。

滚轮平移，按住 Command 或 Ctrl 滚动以缩放。画布聚焦后可按住空格拖动平移，也可使用中键拖动。缩放控制支持整稿、选区和 100% 三个定位操作。双击文本进入编辑，离开输入框或按 Command/Ctrl+Enter 提交，Escape 取消。

属性面板随选区优先显示尺寸和布局、文字排版、图片设置或组件实例内容。适用于选区的各节内容直接显示，可在面板内滚动查看。自由定位的子图层可以相对父画框对齐，多选可以对齐或等距分布，也能批量修改共有的填充、不透明度、圆角和字号，锁定的图层跳过。

位置、尺寸、角度、间距和内边距在画布和属性面板之间实时同步。用 Tab 可以连续编辑数值，按 Esc 恢复当前编辑。文字排版支持字体、字重、字号、行高、字距和段落对齐，应用于画布、文字编辑和导出。填充和描边可添加多条，每条独立设置颜色、不透明度和显隐。用左侧拖柄改变叠放顺序，拖动中同步预览，松手提交一次，取消恢复原顺序。聚焦拖柄时也可用方向键移动。画框、矩形、椭圆和图片的每条描边可设置内侧、居中和外侧。外观还支持独立圆角、裁剪和阴影。

文字属性的字体按钮可搜索本机已安装的字体，也可直接输入名称。「局部样式」可在同一文字层内选取一段文字，设置字体、字号、加粗、颜色或共享颜色样式。点击色块可在取色器切换 HEX、RGBA 或 HSLA，使用屏幕取色和透明度滑杆。填充取色器还可切换纯色、线性或径向渐变以及图片，选择正片叠底、滤色等混合模式。渐变色标可在预览条上拖动，也可精确输入颜色、位置和不透明度。链形按钮可引用共享颜色。拖动时画布与对应字段同步预览，松手提交一次，取消恢复原值。

图片填充支持填满、完整显示和拉伸。可从项目图库或本机选择图片，也可输入项目路径或支持跨域访问的 HTTPS 图片链接。通过链接导入的图片会保存到当前项目，稿件和导出使用项目内的图片。

弹性布局支持水平或垂直排列，也可在空间不足时自动换行。九宫格设置对齐，间距可选择固定间距、两端对齐和环绕均分，内边距可按横纵成对设置或分别编辑四边。宽度和高度可按各自支持的模式选择填充或适应内容，宽度可加最小值和最大值。取消勾选可保留当前尺寸。子图层可绝对定位，切回自由布局时保留已排好的位置和尺寸。

选中弹性布局画框后，点击右侧「弹性布局」标题旁的画布调整图标，即可拖动边缘的内边距手柄和图层之间的间距手柄。再次点击图标或按 Esc 退出。内边距沿用面板的成对或四边独立设置。自动分布下，间距拖动从当前实际间距起步，松手保存为固定间距。拖动实时重排，松手只提交一次，拖动中按 Esc 恢复原值。

插入或替换图片时，可在缩略图图库选择项目素材，点「从本机导入」选择文件，或按 Ctrl/Cmd+V 粘贴图片。选中的图片会显示大图预览，确认后才应用到画布。导入的图片在确认时保存在当前项目根目录的 `design-assets` 中，其他稿件也可以复用。在画布上直接粘贴会插入新图层。图片适应方式可选择填满或完整显示。进入裁切后可在画布拖动图片或输入位置百分比。拖动时同步显示裁切，松手提交一次，按 Esc 恢复拖动前的位置。

可以在属性面板把图层或画框创建为主组件。当前文件的主组件可通过「插入组件」复用。实例的文字和图片可以单独替换或恢复为继承的内容，其余样式继续跟随主组件。实例可以定位到主组件或分离为独立图层。删除主组件前需要分离或移除已有实例。

主组件可添加并命名加载、禁用等变体。实例可切换变体，并保留对应图层上的文字和图片覆盖。画布顶部的「设计资源库」用色卡和字样预览命名颜色及文字样式，点选本稿样式可编辑。属性面板可将填充、描边、阴影、渐变色标或文字链接到样式。

在目标稿件打开「设计资源库 → 共享库」，连接同一项目根目录下的源稿件。连接后可在属性面板的样式列表和「插入组件」中直接引用源资源。源稿件保存后，打开的引用稿件会自动刷新，仍沿用实例自己改过的文字和图片。源稿件移动或改名时，可在共享库重新连接到新路径。

选中按钮或其他图层后，在属性面板的「原型交互」中设置跳转到画板、返回、打开浮层或关闭浮层。目标从顶层画板中选取。点击顶部的「播放原型」可从选中图层所在的画板开始操作，预览中可切换起始画板和重新播放。

选中图层后，属性面板可复制或保存 HTML 和 HTML + Tailwind，也可导出独立 SVG，或按 1×、2×、3× 导出透明 PNG。HTML 保留弹性布局的填充、适应内容、换行和宽度限制。单独导出一个未旋转或翻转的弹性画框时，页面以窗口宽度排版。SVG 保留矢量轮廓、渐变和裁切，图片内嵌，命名字体由打开文件的环境提供。画布和图层树的右键菜单共用复制、粘贴替换、层级、编组、布局、组件、翻转和删除命令。像素网格与吸附偏好保存在本机。包含图片的图层可以在同一项目根目录的设计之间粘贴。

跨稿粘贴会保留图层当前的外观。目标稿已连接相应样式库时，粘贴的图层会继续跟随共享样式更新。把按钮和它跳转的画板一起复制时，粘贴后的按钮会跳转到新画板。

`packages/features/design` 持有版本化文档、typed operation、设计工作区和画布。v5 使用有序图层树保存画板及图形，保存叠加填充和描边、样式与组件引用、文字片段、蒙版和原型连线。共享库按稿件 ID、项目内路径和资源 ID 定位。渲染时通过现有稿件读取链路解析引用及其依赖，源文件刷新独立于目标稿件的写入和撤销历史。v1 到 v4 稿件在读取时迁移，原有单条描边进入有序描边列表，编辑后以 v5 保存。Yoga 解析布局，Konva 根据计算后的图层变换渲染，画布按视口裁剪渲染范围。两者在打开稿件时按需加载。项目图片保存为相对根目录的引用，并通过工作区文件预览读取。

拖动、旋转和缩放手柄的预览留在 renderer。批量移动、成组和跨画框拖放在松手或执行命令时提交一次。Runtime 通过 workspace adapter 校验变更批次和文件 revision，再原子替换文件。撤销与重做沿用同一提交路径，历史保留在 Runtime 会话内。现有文件监听负责刷新外部修改，磁盘内容变化会使旧撤销历史失效。

图层结构、移动事务、布局和组件交互参考 [Penpot 的图层移动协议](https://github.com/penpot/penpot/blob/develop/common/src/app/common/files/changes.cljc#L231-L253)、[Flex Layout](https://help.penpot.app/user-guide/designing/flexible-layouts/)和[组件](https://help.penpot.app/user-guide/design-systems/components/)。
