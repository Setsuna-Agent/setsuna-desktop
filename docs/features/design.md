# 设计画布

点击左侧导航栏的「设计」图标进入独立工作区。首次进入时，首页直接显示各项目及其绑定目录中的稿件。项目与目录可用于筛选，重叠目录中的同一稿件以最接近文件的绑定目录显示一次，同名的独立稿件通过来源区分。新建设计时选择保存的项目和目录。首页按目录独立加载并监听变化，子目录中的新稿件会自动出现。画布顶部可切换稿件或返回之前的列表筛选。项目文件树打开 `*.design.json` 也会定位到该工作区，顶栏前进和后退可恢复当时选中的稿件。

设计首页卡片和画布顶部稿件名旁的 `…` 菜单提供「移动到其他项目」和「删除设计稿」。移动时选择目标项目的绑定目录，目标目录会保留稿件引用的图片和共享库。目标已有同名且内容不同的资源时，移动失败并保留源稿。确认删除后会移除设计稿文件，原目录中共用的图片和库文件保留。如果源目录下其他稿件仍将这份稿件作为共享库，移动和删除都会提示引用关系。

每个窗口的会话保存最后打开的设计稿或首页筛选。切回设计时恢复这个位置。关闭窗口时停在设计页，重新打开同一窗口位置会直接恢复设计。被删除的稿件回到设计列表。恢复只读取已有窗口会话下的一条本地记录，目录扫描和稿件加载按需异步执行。

画布顶部工具条水平居中，集中放置绘制、插入、撤销、重做、原型预览和选区操作。点击插入图片、图标库、变量或设计资源库，面板从对应图标下方展开，画布可继续操作。选择形状工具后可以拖出尺寸，也可以单击插入。拖画时，起点和终点靠近画框外沿都会吸附，并显示参考线。新建画框、矩形、椭圆和多边形默认使用 1px 黑色描边，内部透明。画框和矩形的圆角半径从 0 开始。用顶部的画框图标新建画板，选中画板后可在属性栏的尺寸区按名称或尺寸搜索并应用预设。

多边形可在属性面板设置 3 至 32 条边。钢笔点按添加直线节点，按住拖动生成贝塞尔手柄，单击起点闭合。已有至少两个锚点时，按 Enter 或 Esc 可保存为开放路径。只有一个锚点时，按 Esc 可清除该点。完成的路径默认使用 1px 黑色描边，拐点采用尖角连接。保存后可通过「编辑节点」拖动锚点和手柄。整条路径完成或编辑拖动松手时提交一次。

点击顶栏的「绘画模式」可切换钢笔、画笔和铅笔，快捷键分别为 P、B、N。下方控制条可设置纯色、渐变、透明度、混合模式和粗细。画笔与铅笔可以选择笔触预设，按住 Command 或 Ctrl 点击已有笔迹可以取样。拖画时实时预览，按 Esc 可取消当前笔迹。画笔和铅笔可以连续落笔，每一笔在松手后按顺序保存为单独的矢量图层，可逐笔撤销。画笔的笔触保存为闭合轮廓，铅笔保留描边和中心路径。

在同一层级多选闭合形状后，右键可合并路径，或用底部形状减去上方形状。相减得到的孔洞会保留在 SVG 中。多选形状和内容后可用最上方的闭合形状创建蒙版。蒙版和内容仍可在图层树中单独编辑，也可从右键菜单移除蒙版。

图标库使用应用已安装的 Lucide 图标，按名称搜索并连续滚动浏览。选中 Lucide 图标后，可在右侧「图标」切换形状，沿用原来的尺寸、位置、填充和描边。

图标库的「导入 SVG」可选择本机文件。也可将 SVG XML 或剪贴板中的 SVG 文件用 Ctrl/Cmd+V 直接贴到画布。导入支持基础形状、路径、变换、纯色填充和描边。多色 SVG 按路径保留各自的外观，可在图层树选中子图层修改。带渐变、蒙版、滤镜或文字的文件需先转为基础矢量形状。

在形状菜单里选「嵌入网页」，放置图层后可在画布工具条或浏览器属性栏填写网址。打开稿件后，画布会加载可见网页图层已保存的网址。网页图层可见时，工具条贴着网页上沿，可直接拖动图层、刷新或切换设备。点播放图标进入网页交互，点工具条上的 Esc 或按 Esc 回到图层编辑。属性栏的放大图标可在画布内容区展开预览。设备预设改变网页视口，可单独调整网页缩放。稿件会保存网址、设备和缩放，支持 HTTP、HTTPS 和本机开发站点。浏览器图层也支持上下文、自动布局、圆角、描边和阴影。

在形状菜单里选「脚本」，在属性栏填写相对于项目根目录的 `.js` 文件路径，或点路径右侧的导入图标选择本机文件。导入会把文件复制到项目的 `design-assets` 目录并关联到当前图层。脚本保存后会重新生成。改参数时画布同步预览，确认输入后将参数保存到当前图层。点击「转换为图层」可把当前参数生成的内容保存为可编辑画框，撤销时恢复脚本及其参数。

点击属性栏「脚本」标题旁的脚本库图标，可以选用折线图、柱状图和点阵。选用时会把一份可编辑的 `.js` 文件复制到项目的 `design-assets` 目录，并关联到当前图层。

脚本通过 `canvas.width` 和 `canvas.height` 读取图层尺寸，通过 `canvas.input` 读取参数，并用 `return` 返回一组图层。参数写在文件开头的 `/** … */` 注释里，支持 `string`、`number`、`color`、`boolean`。字符串默认值使用双引号，颜色使用十六进制。

```js
/**
 * @input bars: number = 4
 * @input color: color = #3D99FF
 */
const count = Math.max(1, Math.min(64, Math.round(canvas.input.bars)));
return Array.from({ length: count }, (_, index) => ({
  kind: 'rectangle',
  x: (canvas.width / count) * index,
  y: 0,
  width: canvas.width / count * 0.8,
  height: (canvas.height / count) * (index + 1),
  cornerRadius: 4,
  fills: [{ color: canvas.input.color }],
}));
```

脚本可生成画框、矩形、椭圆、文本和矢量。画框用 `children` 声明子图层。沙箱只接收图层尺寸和声明的参数，执行时间上限为两秒，最多可返回 512 个图层。

拖动空白区域框选，Shift 单击增减选区。图层可批量移动、复制、对齐、等距分布、成组和解组。拖动选框手柄可调整尺寸和旋转。移动自由布局图层或拉伸平行的边时，靠近父画框会优先吸附外边缘，也能和附近图层的边缘对齐。移动时还可以将两个图层的中心对齐。按 Alt 可临时关闭吸附。图层树支持折叠、拖动排序、跨画框移动、隐藏和锁定。自由图层按前后叠放展示，弹性布局的子图层按排列顺序展示。从图层树拖到画布时，图层会跟随指针，目标弹性布局会实时预留插入位置。松手保存一次，按 Esc 取消并恢复原布局。

滚轮平移，按住 Command 或 Ctrl 滚动以缩放。画布聚焦后可按住空格拖动平移，也可使用中键拖动。画布内容区右下角可放大、缩小，点击百分比可打开菜单，选择适应画布、适应选区或 50%、100%、200%。画布聚焦时，Shift+1 适应整稿，Shift+2 适应选区。双击文本进入编辑，离开输入框或按 Command/Ctrl+Enter 提交，Escape 取消。

左侧图层栏的收起按钮位于画布左上角，与右侧属性栏的收起按钮在同一行。左右侧栏距各自侧边均为 12px，默认等宽。拖动靠画布的边缘可分别调整宽度，聚焦边缘后也可用左右方向键调整。收起再展开时会恢复调整后的宽度。选中图层后，右侧属性栏从画布顶部占满可用高度。清空选区或手动收起会隐藏属性栏，再选图层即可打开。自由定位的子图层可以相对父画框对齐，多选可以对齐或等距分布，也能批量修改共有的填充、不透明度、圆角和字号，锁定的图层跳过。

位置、尺寸、角度、间距和内边距在画布和属性面板之间实时同步。用 Tab 可以连续编辑数值，按 Esc 恢复当前编辑。文字排版支持字体、字重、字号、行高、字距和段落对齐，应用于画布、文字编辑和导出。填充和描边可添加多条，每条独立设置颜色、不透明度和显隐。用左侧拖柄改变叠放顺序，拖动中同步预览，松手提交一次，取消恢复原顺序。聚焦拖柄时也可用方向键移动。画框、矩形、椭圆和图片的每条描边可设置内侧、居中和外侧。外观还支持独立圆角、裁剪和阴影。

文字属性的字体按钮打开可搜索的列表。「全部字体」包含系统字体和已导入的字体。「自定义字体 → 管理自定义字体」可导入或移除 TTF、OTF、WOFF 和 WOFF2，单个文件上限为 20 MB。导入的字体保存在应用本地，重开应用或切换稿件后都能使用。移除字体后，文字会按原字体名称查找系统字体，再使用默认回退字体。

也可以直接输入字体名称。「局部样式」可在同一文字层内选取一段文字，设置字体、字号、加粗、颜色或共享颜色样式。点击色块可在取色器切换 HEX、RGBA 或 HSLA，使用屏幕取色和透明度滑杆。填充和描边共用取色器，顶部可切换纯色、渐变和图片，也可选择正片叠底、滤色等混合模式。

渐变支持线性、径向、角度和菱形。打开渐变面板后，可直接在画布拖动渐变手柄和色标，也可在预览条上拖动或输入色标的颜色、位置与不透明度。链形按钮可引用共享颜色。拖动时画布与对应字段同步预览，松手提交一次，取消恢复原值。

图片填充和图片描边支持填满、完整显示和拉伸。可从项目图库或本机选择图片，也可输入项目路径或支持跨域访问的 HTTPS 图片链接。通过链接导入的图片会保存到当前项目，稿件和导出使用项目内的图片。

在填充的色块弹层切换到「着色器」，可从预设的缩略图选择，导入 `.glsl` 文件，或输入项目内的相对路径。使用预设时会将其 GLSL 源码保存到项目。着色器支持 WebGL 的 GLSL ES 1.00 和 3.00 片段着色器。`@resolution` 和 `@time` 自动传入渲染尺寸和时间。参数上方的 `@label`、`@default`、`@range`、`@step` 和 `@color` 注解决定编辑器控件及其默认值。纹理可取项目图片、当前图层背后的内容，或当前图层自身的普通填充和子图层。导出以静态图像保留着色器结果，背景纹理取自导出范围内的图层。

弹性布局支持水平或垂直排列，也可在空间不足时自动换行。九宫格设置对齐，间距可选择固定间距、两端对齐和环绕均分，内边距可按横纵成对设置或分别编辑四边。宽度和高度可按各自支持的模式选择填充或适应内容，宽度可加最小值和最大值。取消勾选可保留当前尺寸。子图层可绝对定位。在弹性画框里拖画形状时会保留绘制坐标，单击插入的形状随布局排列。切回自由布局时保留已排好的位置和尺寸。

选中弹性布局画框后，点击右侧「弹性布局」标题旁的画布调整图标，即可拖动边缘的内边距手柄和图层之间的间距手柄。再次点击图标或按 Esc 退出。内边距沿用面板的成对或四边独立设置。自动分布下，间距拖动从当前实际间距起步，松手保存为固定间距。拖动实时重排，松手只提交一次，拖动中按 Esc 恢复原值。

插入或替换图片时，可在缩略图图库选择项目素材，点「从本机导入」选择文件，或按 Ctrl/Cmd+V 粘贴图片。选中的图片会显示大图预览，确认后才应用到画布。导入的图片在确认时保存在当前项目根目录的 `design-assets` 中，其他稿件也可以复用。在画布上直接粘贴会插入新图层。图片适应方式可选择填满或完整显示。进入裁切后可在画布拖动图片或输入位置百分比。拖动时同步显示裁切，松手提交一次，按 Esc 恢复拖动前的位置。

可以在属性面板把图层或画框创建为主组件。在「设计资源库 → 组件」可以搜索当前稿件和已连接共享库中的组件和变体，拖到画布上松手后创建实例。落点所在的画板能容纳实例时会将它放在画板内，放不下时会在落点创建独立的实例。属性栏和画布空白处的右键菜单也提供「插入组件」。实例的文字和图片可以单独替换或恢复为继承的内容，其余样式继续跟随主组件。实例可以定位到主组件或分离为独立图层。删除主组件前需要分离或移除已有实例。

组件搜索框右侧的图标可切换双列卡片和列表。首次打开显示双列卡片，切换稿件或重启应用后沿用本机上次选择的视图。

主组件可添加并命名加载、禁用等变体。实例可切换变体，并保留对应图层上的文字和图片覆盖。点击画布顶部的「变量」图标打开变量表。「设计资源库」提供组件、文字样式和共享库。属性栏的变量链接位于对应控件内的右侧，选择「局部值」可解除绑定并保留当前值。

| 变量类型 | 可绑定的属性 |
| --- | --- |
| 颜色 | 填充、描边、阴影、渐变色标、文字局部颜色。变量颜色的不透明度与绑定属性自身的不透明度相乘 |
| 数字 | 自由定位的 X/Y、旋转、固定宽高、最小与最大宽度、间距、内边距、圆角、图层与绘制项透明度、描边宽度、阴影几何、多边形边数、图片裁剪位置、字号、字重、行高和字距。透明度和裁剪百分比使用 0 到 1 的值 |
| 字符串 | 文字内容、字体族 |
| 布尔值 | 隐藏图层、画框裁剪、弹性布局换行 |

在「变量」面板顶部切换集合，点击当前集合名可打开操作菜单，集合列表旁的 `+` 可新建集合。每个集合的变量以名称为行、模式为列并排编辑。点击本地模式的列名可重命名，自建模式也可通过同一个菜单删除。新增模式的单元格默认继承基础值。新增变量使用表格底部的「添加变量」。颜色变量和手动添加的纯色填充从黑色开始，颜色单元格可编辑 HEX 和不透明度。手动添加描边从 1px 黑色尖角连接开始。文字样式也可引用排版变量。

变量行末的 `…` 菜单可重命名、创建副本、移动到本稿的其他集合或删除。移动时保留已有绑定和模式值，目标集合会补充缺少的模式。

点击变量值旁的链条图标可搜索并引用同类型变量。各模式可以分别选择引用。绑定颜色后，色值位置显示来源变量名。拖动修改来源颜色时，引用单元格、属性栏和画布同步预览。选择「无」会解除当前单元格的引用并保留当前值，随后可直接改色。属性栏的数字链接始终可用，暂无兼容变量时可从菜单打开变量表。选择「局部值」解除链接。在画布上移动图层时，实际改变的位置轴会改用局部值。画板根据每个来源集合选中的模式解析引用。

选中顶层画板，在属性面板的「变量模式」中为本稿和共享库的各个集合分别选模式。例如同一画板可同时选蓝色强调色和深色模式。组件实例继承所在画板的选择，文字覆盖仍以实例为准。引用暂不可用或值与字段不兼容时使用稿件保存的局部值。原型和导出按画板当前选择计算。

在目标稿件打开「设计资源库 → 共享库」，连接同一项目根目录下的源稿件。连接后可在属性面板的样式列表和「插入组件」中直接引用源资源。源稿件保存后，打开的引用稿件会自动刷新，仍沿用实例自己改过的文字和图片。选中已连接的源稿件，点击「取消链接」可把相关实例分离为本地图层，并把直接绑定的共享样式和变量转换为局部值。源稿件移动或改名时，可在共享库重新连接到新路径。

选中按钮或其他图层后，在属性面板的「原型交互」中设置跳转到画板、返回、打开浮层或关闭浮层。目标从顶层画板中选取。点击顶部的「播放原型」可从选中图层所在的画板开始操作，预览中可切换起始画板和重新播放。

选中图层后，属性面板可复制或保存 HTML 和 HTML + Tailwind，也可导出独立 SVG，或按 1×、2×、3× 导出透明 PNG。HTML 保留弹性布局的填充、适应内容、换行和宽度限制。单独导出一个未旋转或翻转的弹性画框时，页面以窗口宽度排版。SVG 保留矢量轮廓、渐变和裁切，图片内嵌。HTML 和 SVG 会嵌入实际用到且允许嵌入的自定义字体，其余字体由打开文件的环境提供。画布和图层树的右键菜单共用复制、粘贴替换、层级、编组、布局、组件、翻转和删除命令。像素网格与吸附偏好保存在本机。包含图片的图层可以在同一项目根目录的设计之间粘贴。

跨稿粘贴会保留图层当前的外观。目标稿已连接相应资源库时，粘贴的图层会继续跟随共享样式和变量更新。把按钮和它跳转的画板一起复制时，粘贴后的按钮会跳转到新画板。

`packages/features/design` 持有版本化文档、typed operation、设计工作区和画布。v7 在原有样式资源上保存多个变量集合，画板模式按稿件与集合定位。绑定与局部值同存，跨稿引用按稿件 ID、项目内路径和资源 ID 定位。画布计算布局前按画板解析变量及其依赖，源稿件刷新独立于目标稿件的写入和撤销历史。v1 到 v6 原有颜色、变量和模式进入默认集合。v8 读取旧稿时将原来隐式的填充与矢量描边连接写入模型，保留旧稿外观。v9 将渐变、图片和混合模式纳入描边。v10 增加位置、旋转、宽度限制、裁剪位置和多边形边数的变量绑定。编辑器可以打开 v1 至 v12 的稿件，更改内容后会以 v12 保存。Yoga 解析布局，Konva 根据计算后的图层变换渲染，画布按视口裁剪渲染范围。两者在打开稿件时按需加载。项目图片保存为相对根目录的引用，并通过工作区文件预览读取。

拖动、旋转和缩放手柄的预览留在 renderer。批量移动、成组和跨画框拖放在松手或执行命令时提交一次。Runtime 通过 workspace adapter 校验变更批次和文件 revision，再原子替换文件。撤销与重做沿用同一提交路径，历史保留在 Runtime 会话内。现有文件监听负责刷新外部修改，磁盘内容变化会使旧撤销历史失效。

图层结构、移动事务、布局和组件交互参考 [Penpot 的图层移动协议](https://github.com/penpot/penpot/blob/develop/common/src/app/common/files/changes.cljc#L231-L253)、[Flex Layout](https://help.penpot.app/user-guide/designing/flexible-layouts/)和[组件](https://help.penpot.app/user-guide/design-systems/components/)。
