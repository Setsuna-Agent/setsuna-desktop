# 设计画布

设计首页的「新建设计」弹窗可填写稿件名称、选择保存位置和关联项目。默认保存到应用本地数据目录下的 `runtime/designs`。已有项目中的 `*.design.json` 保留原位，仍可从设计首页或项目文件树打开。

将 Pencil 2.x 的 `.pen` 文件拖到设计首页，可选择保存位置和关联项目，生成新的可编辑稿件。同文件中的组件实例和选定变体展开为独立图层，变量按图层继承的主题取值。导入范围为当前文件中的图层，网页和脚本图层保存为待配置的占位图层。 [Pencil 文件格式](https://docs.pencil.dev/for-developers/the-pen-format)

在画布顶栏切换项目时，画布会打开所选项目的第一份稿件。没有稿件时显示空画布。稿件菜单第一项「新建设计稿」会直接创建并打开，重名时追加序号。有稿件时保存到当前稿件所在目录。空项目优先使用第一个已绑定目录，也可以在本地设计目录保存无绑定目录的项目稿件。点返回箭头回到设计首页。稿件的项目关联保存在本机，供项目筛选和设计聊天使用。未关联时，设计聊天使用独立的临时工作区。

设计首页的稿件 `…` 菜单可关联项目、更换项目或选择「不关联项目」。同一菜单提供「更改保存位置」和「删除设计稿」。更改位置会将稿件和它引用的依赖保存到所选目录，并保留项目关联。目标有冲突或稿件正被其他设计作为共享库引用时，会保留源稿。确认删除只移除稿件，其他稿件共用的素材和库文件保留。首页按目录独立加载并监听变化，重叠目录中的同一份文件只显示一次。

项目源文件夹不可用时，首页静默跳过该目录并继续加载其他目录。窗口重新获得焦点时会重新读取已恢复的目录。

每个窗口的会话保存最后打开的设计稿、空项目画布或首页筛选。切回设计时恢复这个位置。关闭窗口时停在设计页，重新打开同一窗口位置会直接恢复设计。被删除的稿件回到设计列表。恢复只读取已有窗口会话下的一条本地记录，目录扫描和稿件加载按需异步执行。

## 在外部 Agent 中读取设计

在稿件的「设计设置 → MCP」开启 Codex 或 Claude Code，Setsuna 会在对应客户端的用户级配置中添加 `setsuna-design`。关闭开关会先撤销本机访问和重启时恢复授权的记录，再移除 Setsuna 添加的配置。客户端配置清理失败时，本机访问仍保持关闭。已经打开的 Agent 会话可在重新加载 MCP 或重开后发现新配置。其他客户端可通过「复制 MCP 配置」导入 `mcpServers` 格式的 stdio 配置。「撤销访问」会取消手动接入中正在进行的读取，并让已复制的配置失效。再次接入需要复制新的配置。

外部 Agent 可以用 `get_active_design` 获取当前稿件、画板和画布选中的图层，用 `inspect_design` 查看图层结构、尺寸、布局和样式，再用 `preview_design` 获取指定图层或画板的 PNG。读取限定在最近使用的 Setsuna 窗口中当前可见的稿件。工具接受稿件 ID 和 revision，用来确认后续读取仍指向同一份设计。目标图层沿用具名 Agent 光标和流光。

浏览结构时传 `mode:"index", maxDepth:1`，先看根图层及其直接子层。用 `name` 按完整图层名查找，或传 `layerIds` 一次读取最多 32 个指定图层。`maxDepth:0` 只读取指定层本身。查询结果中的 `layerIds` 是请求的根图层，`selection` 是画布当前选区。按 `nextOffset` 翻页时保留同一份 `documentId`、`revision`、查询条件和 `limit`。

设计 MCP 由独立的 stdio 入口连接本机应用。Main 用每个接入来源的私有凭据认证请求，并转发给当前画布，画布切换或关闭会取消未完成的读取。启动时已授权的连接在首帧揭示后恢复。预览沿用画布的 PNG 渲染，外部工具只提供读取操作。

## 在主对话中设计

在项目对话里问「这个项目有哪些设计图」，或输入 `@` 按名称选择关联的稿件。保存在本地和其他文件夹的关联稿也会出现在结果中。

直接说「设计一个登录页」可以在右栏打开新画布。新稿默认存本地，在项目对话中自动关联当前项目。Agent 在右栏使用与设计聊天相同的画布命令。检查、选择或编辑图层时，画布会显示 Agent 光标和目标画板的流光。收起画布后，可以从环境面板的「产物」再次打开。这里也收录 Agent 在这次对话中主动发布的文件。

需要并行设计时，可以直接在主对话中分工，例如「让两个子代理分别设计游戏管理页和玩家数据页」。主 Agent 在当前轮次打开稿件后派发任务，每个子代理在同一画布上使用独立的选区和具名光标。切到子代理详情时，画布会在后台继续执行。关闭设计标签会结束这次画布任务。

## AI 设计任务

左侧栏默认打开第一个标签「聊天」，点旁边的「图层」可查看画板和图层。在画布上选中图层后，可直接在聊天中发送要求。例如「把这三张卡片排成一行，预览后把间距调紧一些」。模型可以读取选区内的图层、组件实例和排版边界，提交编辑，再根据画布渲染的 PNG 调整。预览使用当前稿件的字体、图片、脚本输出和网页捕获，最长边为 1024 像素。只有支持图像输入的模型会收到预览工具。发送时没有选区，工具可以设计整份稿件或管理整稿资源。

切回「图层」或收起左栏会保留聊天草稿、待发送的附件和正在执行的任务。聊天复用主聊天的输入器、消息流和附件。画布左侧的设计聊天沿用主聊天的工具目录和权限规则，可以调用已启用的 MCP 服务及插件工具，并用设计工具操作当前稿件。可以用 `/` 选择 Skill 或插件，上传、拖入或粘贴参考图片。发送后的消息与附件随 runtime 线程保存在本机。重新打开同一稿件会恢复上次选择的对话。侧栏顶端可以切换记录或新建对话。选中已有对话后，点归档图标可将它移出历史列表。在「设置 → 归档对话」点「恢复」，记录就会回到原稿件。旧版只记录了所属项目的设计任务收在该项目的只读历史中。

每个新轮次以发送时的选区为起点。聊天中指向其他区块时，模型可按名称查找，或用 `design_inspect({mode:"index",scope:"document"})` 浏览整稿，再用 `design_view({action:"select",ids:[...]})` 自行切换选区。后续省略 ID 的修改和预览使用新选区。每条画布编辑命令通过人工编辑使用的文档服务提交，独立进入撤销历史。命令保存后，当前编辑器会立即重读稿件并选中操作结果。在执行中点击聊天输入器的停止按钮可以继续手工编辑、撤销或重做。其他窗口先行保存时，旧版本的命令会被拒绝，模型可以重新读稿再调整。

打开另一份设计稿、返回设计首页或切到聊天、设置等主页面时，正在提交或执行的设计任务会在后台继续。切回原稿可以查看同一轮的进度和结果。关闭窗口会结束该窗口中正在执行的设计任务。

开启多 Agent 协作后，可以在设计聊天里让主 Agent 分工。例如「让导航和图表两个 Agent 分别修改左侧栏和趋势图」。子 Agent 共用当前稿件，各自选择目标图层。光标旁显示主 Agent 为它起的名字，续做时沿用同一颜色。子 Agent 结束后，它的光标随之消失。并发提交会校验稿件版本，遇到冲突的 Agent 需要重新读稿后再提交。

同一个 Agent 同时查看、预览或编辑多个画板时，每个涉及的画板各显示一个该 Agent 颜色的光标，细光沿目标边框循环移动，光标尖端的光晕缓慢明暗变化。同一画板上的多个目标共用一个光标。开启系统的「减少动态效果」后，光标保持静态。删除后，光标会在图层原来的位置短暂停留。聚焦画布后按 H 可以切到抓手，也可以按住空格拖动、用鼠标中键拖动或缩放查看。AI 保存图层修改时，正在进行的平移可以继续。

设计聊天会显示「检查设计图层」「编辑设计稿」「查询设计资源」等工具名称，悬停可查看原始工具 ID。已有记录沿用相同的展示规则。

绑定画布的设计聊天默认带入内置 Skill「画布设计」，已有对话继续设计时也会生效。改名、改间距等属性修改可以凭保存回执完成。需要判断画面效果时预览相应区块，有具体布局疑问时只检查相关图层。可在 Skill 设置中关闭。[查看中文指引](../../skills/design-canvas/SKILL.zh-CN.md)

用户要求可操作的页面时，设计聊天能在当前对话的工作目录里编写页面或服务端代码，用工作区的命令工具启动本地服务，再把实际监听的网址挂到画框内的网页图层。已有服务可以直接挂载。点图层上沿的播放键即可输入、点击或提交，按 Esc 返回画布。文件和命令沿用聊天的权限及审批设置。用于交付的服务由运行中心管理，聊天轮次结束后可以继续访问，也可以从聊天或运行中心停止。画布撤销作用于网页图层，服务进程和项目源文件分别管理。

生成整页时，先用 `design_resources({kind:"styles"})` 查主题变量。整稿任务可以用一次 `setStyle` 建立缺少的变量，例如 `fields:{styles:{accent:{kind:"color",name:"主色",color:"#4F7CFF"},surface:{kind:"color",name:"卡片底色",color:"#FFFFFF"}}}`。建层时填充或描边直接引用 `styleId`，例如 `fills:[{color:"#4F7CFF",styleId:"accent"}]`。选区任务可以绑定已有变量。变量面板会列出已建的变量，编辑变量值后引用它的图层会一起更新。

页面区块和卡片各自使用画框。行、列和徽章可使用自动布局，图层名可独立于显示文案，例如 `card.orders.link`。文本给定 `width` 时默认使用固定宽度，省略宽度时随文字伸缩。徽章文字垂直居中可在定高画框上使用 `layout:{direction:"horizontal",align:"center",justify:"center",padding:0,gap:0}`。

`design_edit` 的 `insert` 可以在画框上写 `children`，也可以用 `fields.layers` 一次插入多棵树。传 `dryRun:true` 会校验同一批命令和版本，成功返回 `validated:true, applied:false` 和 `layout`。编辑器在临时稿上复用组件投影、Yoga 布局和文字测量，返回目标层与重排层的实际宽高、画布边界，以及试算后任务范围内的裁切、文本溢出和 `fillInHug` 警告。`layout.layerCount`、`issueCount` 给出完整数量，尺寸和问题明细有长度限制。新层 ID 标记为 `temporary:true`，提交后以正式回执为准。运行时仍在文件锁内校验版本和选区。预检和正式建层共用字段校验。无效批次以 `INVALID_LAYERS` 返回 `applied:false` 和 `issues`，每项含字段路径、错误原因，有图层名时含 `layer`。布局缺少必填字段时给出编辑器默认值 `suggestedValue`。诊断超过传输预算时，`omitted` 给出省略条数。正式提交一批只需一次撤销。结果返回当前 `revision`、根图层 `ids`（最多 64 个）、根数量 `count` 和编辑条数 `changes`。画布确认保存版本后，`inserted` 还会返回最多 256 个新图层的 ID、父 ID、名称和最终边界，`insertedCount` 给出新层总数。用 `design_inspect({mode:"index",name:"card.orders.link"})` 可在任务范围内精确找层，同名图层会分别列出。

在 `run_code` 中依次 `await` 写入，下一次使用上一次的 `result.data.revision`。已保存、画布未确认刷新时返回 `applied:true,refreshed:false`；这时应重新检查稿件。版本冲突的错误包含 `code:"REVISION_CONFLICT",applied:false`。

`insertSvg` 使用 SVG 声明的尺寸，省略尺寸时按 viewBox 或路径范围导入。可在同次调用传入父层坐标 `x/y`、`width/height` 和 `strokes`，只传宽或高时等比缩放。图标查询按名称子串匹配，精确同名优先，`exact:true` 只返回同名图标。`fields.icons` 可一次插入最多 64 个带各自位置和样式的 Lucide 图标，共用一次撤销。Harness 插入画框、闭合形状和文本时默认无描边，线段和箭头有可见描边。

`design_edit` 的 `update` 会处理每个显式指定的 ID。组缩放先按编辑器规则更新子层，再应用显式子层修改，整批共用一个 revision 和撤销步骤。可用 `design_resources({kind:"styles"})` 查找 token。使用 `bindTokens` 可一次为不同图层绑定不同属性。

```json
{"action":"bindTokens","revision":"<刚读取的 revision>","fields":{"bindings":[
  {"ids":["label","amount"],"field":"fills.0.color","tokenId":"muted"},
  {"ids":["amount"],"field":"fontSize","tokenId":"bodySize"},
  {"ids":["card"],"field":"layout.gap","tokenId":"spacing"}
]}}
```

绑定项省略 `ids` 时使用命令的目标图层；显式传入命令级 `ids` 时，每项只能取其中的图层。支持图层变量字段、自动布局变量字段、文字样式 `textStyleId`、纯色填充和描边、阴影颜色。引用按画板变量模式解析。目标越界、被锁定或类型不匹配时整批取消。

整板验稿使用 `design_inspect({ids:[boardId],mode:"audit"})`。一次检查所有可见图层，返回 `checked`、`issueCount`、按类别计数的 `summary` 及带图层 ID 和路径的 `issues`。超出传输预算时只对问题明细分页。侧边工具条的「检查布局」使用同一报告，点击条目会选中并缩放到图层。报告区分裁切、仅超出父框、裁切待复核及对比度无法判定。同一裁切边界的报告提供定位用的 `id`、范围内的 `clipperId`、受影响层数 `affectedCount` 和最多四个样例 ID（`examples`）。独立的内层裁切、文字自身溢出分别计数。`mode:"layout"` 保留逐层明细。

整稿范围的 `design_inspect({ids:[],mode:"index"})` 同时返回根图层数量、画板数量和前 64 个画板。较早的稿件可能没有 `lastSaved`。下一次成功保存图层编辑后，该位置随稿件持久化，撤销或重做也会恢复对应的位置。空选区的图层列表用历史图标标记最近保存的画板和区块。

`design_inspect({mode:"layout"})` 默认检查越界、文字裁切或溢出、低对比度，以及被不透明同级矩形或画框完全盖住的文字。越界项包含图层名与选区内的层级路径。对比度按普通文字 4.5:1、大字 3:1 检查，无法确定背景色时列入 `unverifiedContrast`。使用 `checks:["outOfBounds","textOverflow","lowContrast"]` 可只检查指定项目。需要排查模糊的相交时，在 `checks` 中加入 `possibleOverlap`，传入 `includeExpectedOverlaps:true` 可同时查看文字、图标与底板的预期叠层。每类相交每层最多列出 4 个对象并给出总数。每页检查 32 层，使用返回的 `revision` 和 `nextOffset` 翻页。

| 操作范围 | 设计任务可以调用的功能 |
| --- | --- |
| 图层和布局 | 创建、移动、排序、复制粘贴与替换、对齐分布、编组、自动布局、蒙版、布尔运算、锁定与隐藏 |
| 内容与外观 | 编辑文本和局部样式、填充描边、渐变、图片、阴影、矢量节点、画笔和铅笔、SVG 与图标、网页、脚本与着色器 |
| 组件与资源 | 查询可用资源、创建组件和变体、插入与拆离实例、覆写内容。整稿任务还可编辑共享样式、变量、集合与资源库链接 |
| 预览和交付 | 选择或适应图层、缩放和平移、设置像素网格与吸附、读取画布预览、测试原型热点与返回、复制可编辑图层、导出 PNG、SVG、HTML 或 Tailwind HTML |
| 稿件与资产 | 导入项目资产。整稿任务可管理导入字体、新建稿件，以及在设计工作区中移动或删除当前稿件。移动、删除和移除字体保留人工确认 |

画布撤销作用于稿件内容。资产文件、已安装字体、稿件移动或删除、系统剪贴板和已保存的导出文件各自沿用原有操作语义。工具和文档契约位于 `packages/features/design/src/contracts`，命令规划和预览在 `renderer/agent`，运行时在持有文件写锁时校验版本及选区范围。

## 画布编辑

画布工具条默认竖排在左侧栏右边，依次是导航和形状工具组。左侧栏和上方文件栏默认等宽，可拖动侧栏边缘单独调整宽度。顶部工具条与文件栏同排，底部工具条与缩放控件同排。收起侧栏后，侧边工具条移到展开按钮正下方。选中可编辑图层后，图层操作菜单出现在工具条末尾。撤销、重做、原型预览和设置固定在画布右上角，属性栏从这组按钮的下方开始。窗口空间不足时可滚动工具条。点击插入图片、图标库、变量或设计资源库，面板优先从对应图标朝画布内展开。选择形状工具后可以拖出尺寸，也可以单击插入。拖画时，起点和终点靠近画框外沿都会吸附，并显示参考线。新建画框、矩形、椭圆和多边形默认使用 1px 黑色描边，内部透明。画框和矩形的圆角半径从 0 开始。用工具条的画框图标新建画板，选中画板后可在属性栏的尺寸区按名称或尺寸搜索并应用预设。

在画布工具栏点击齿轮打开「设计设置」。可切换画布背景预设、点阵或网格线、像素网格和吸附选项。点阵和网格线分别记录各自的间距。「外观」可设置画布主题、工具条位置和图层缩略图显示。缩略图开关也适用于设计资源库预览。「快捷键」支持搜索、录入、删除和恢复画布的工具、缩放与图层操作绑定。设置即时保存到本机，并应用于打开的设计画布。

多边形可在属性面板设置 3 至 32 条边。钢笔点按添加直线节点，按住拖动生成贝塞尔手柄，单击起点闭合。已有至少两个锚点时，按 Enter 或 Esc 可保存为开放路径。只有一个锚点时，按 Esc 可清除该点。完成的路径默认使用 1px 黑色描边，拐点采用尖角连接。保存后可通过「编辑节点」拖动锚点和手柄。整条路径完成或编辑拖动松手时提交一次。

点击工具条的「绘画模式」可切换钢笔、画笔和铅笔，默认快捷键分别为 P、B、N。旁边的笔触面板可设置纯色、渐变、透明度、混合模式和粗细。画笔与铅笔可以选择笔触预设，按住 Command 或 Ctrl 点击已有笔迹可以取样。拖画时实时预览，按 Esc 可取消当前笔迹。画笔和铅笔可以连续落笔，每一笔在松手后按顺序保存为单独的矢量图层，可逐笔撤销。画笔的笔触保存为闭合轮廓，铅笔保留描边和中心路径。

在同一层级多选闭合形状后，右键可合并路径，或用底部形状减去上方形状。相减得到的孔洞会保留在 SVG 中。多选形状和内容后可用最上方的闭合形状创建蒙版。蒙版和内容仍可在图层树中单独编辑，也可从右键菜单移除蒙版。

图标库使用应用已安装的 Lucide 图标，按名称搜索并连续滚动浏览。选中 Lucide 图标后，可在右侧「图标」切换形状，沿用原来的尺寸、位置、填充和描边。

图标库的「导入 SVG」可选择本机文件。也可将 SVG XML 或剪贴板中的 SVG 文件用 Ctrl/Cmd+V 直接贴到画布。导入支持基础形状、路径、变换、纯色填充和描边，以及文件内通过 `url(#id)` 引用的线性渐变。渐变支持色标透明度和 `gradientTransform`。多色 SVG 按路径保留外观，子图层可继续编辑。其他渐变类型、渐变继承、蒙版、滤镜和文字仍需先转换。

在形状菜单里选「嵌入网页」，放置图层后可在画布工具条或浏览器属性栏填写网址。打开稿件后，画布会加载可见网页图层已保存的网址。网页图层可见时，工具条贴着网页上沿，可直接拖动图层、刷新或切换设备。点播放图标进入网页交互，点工具条上的 Esc 或按 Esc 回到图层编辑。属性栏的放大图标可在画布内容区展开预览。设备预设改变网页视口，可单独调整网页缩放。稿件会保存网址、设备和缩放，支持 HTTP、HTTPS 和本机开发站点。浏览器图层也支持上下文、自动布局、圆角、描边和阴影。

在形状菜单里选「脚本」，在属性栏填写相对于项目根目录的 `.js` 文件路径，或点路径右侧的导入图标选择本机文件。导入会把文件复制到项目的 `design-assets` 目录并关联到当前图层。脚本保存后会重新生成。改参数时画布同步预览，确认输入后将参数保存到当前图层。点击「转换为图层」可把当前参数生成的内容保存为可编辑画框，撤销时恢复脚本及其参数。

点击属性栏「脚本」标题旁的脚本库图标，可以选用折线图、柱状图和点阵。选用时会把一份可编辑的 `.js` 文件复制到项目的 `design-assets` 目录，并关联到当前图层。

脚本通过 `canvas.width` 和 `canvas.height` 读取图层尺寸，通过 `canvas.input` 读取参数，并用 `return` 返回一组图层。参数写在文件开头的 `/** … */` 注释里，支持 `string`、`number`、`color`、`boolean`。字符串默认值使用双引号，颜色使用十六进制。

```js
/**
 * @input bars: number = 4
 * @input color: color = #3D99FF
 */
const count = Math.max(1, Math.min(64, Math.round(canvas.input.bars)));
return Array.from({ length: count }, (_, index) => ({
  kind: 'rectangle',
  x: (canvas.width / count) * index,
  y: 0,
  width: canvas.width / count * 0.8,
  height: (canvas.height / count) * (index + 1),
  cornerRadius: 4,
  fills: [{ color: canvas.input.color }],
}));
```

脚本可生成画框、矩形、椭圆、文本和矢量。画框用 `children` 声明子图层。沙箱只接收图层尺寸和声明的参数，执行时间上限为两秒，最多可返回 512 个图层。

拖动空白区域框选，Shift 单击增减选区。图层可批量移动、复制、对齐、等距分布、成组和解组。拖动选框手柄可调整尺寸和旋转。移动自由布局图层或拉伸平行的边时，靠近父画框会优先吸附外边缘，也能和附近图层的边缘对齐。移动时还可以将两个图层的中心对齐。按 Alt 可临时关闭吸附。图层树支持折叠、拖动排序、跨画框移动、隐藏和锁定。自由图层按前后叠放展示，弹性布局的子图层按排列顺序展示。从图层树拖到画布时，图层会跟随指针，目标弹性布局会实时预留插入位置。松手保存一次，按 Esc 取消并恢复原布局。

滚轮平移，按住 Command 或 Ctrl 滚动以缩放。画布聚焦后可按住空格拖动平移，也可使用中键拖动。画布内容区右下角可放大、缩小，点击百分比可打开菜单，选择适应画布、适应选区或 50%、100%、200%。画布聚焦时，Shift+1 适应整稿，Shift+2 适应选区。双击文本进入编辑，离开输入框或按 Command/Ctrl+Enter 提交，Escape 取消。

左侧栏的收起按钮位于栏头右端。收起后，展开按钮在原栏头高度，与上方文件工具栏左对齐。左右侧栏距各自侧边均为 12px。图层与聊天共用的左栏从文件导航下方铺到底部边距，空列表也占满可用高度。默认宽度为 384px，窄窗口中按画布可用空间缩小。拖动靠画布的边缘可分别调整宽度，聚焦边缘后也可用左右方向键调整。收起再展开时会恢复调整后的宽度。选中图层后，右侧属性栏从画布顶部占满可用高度。清空选区或手动收起会隐藏属性栏，再选图层即可打开。自由定位的子图层可以相对父画框对齐，多选可以对齐或等距分布，也能批量修改共有的填充、不透明度、圆角和字号，锁定的图层跳过。

位置、尺寸、角度、间距和内边距在画布和属性面板之间实时同步。用 Tab 可以连续编辑数值，按 Esc 恢复当前编辑。文字排版支持字体、字重、字号、行高、字距和段落对齐，应用于画布、文字编辑和导出。填充和描边可添加多条，每条独立设置颜色、不透明度和显隐。用左侧拖柄改变叠放顺序，拖动中同步预览，松手提交一次，取消恢复原顺序。聚焦拖柄时也可用方向键移动。画框、矩形、椭圆和图片的每条描边可设置内侧、居中和外侧。外观还支持独立圆角、裁剪和阴影。

文字属性的字体按钮打开可搜索的列表。「内置字体」包含 Geist、Geist Mono、Inter、DM Sans、Source Serif 4 和 JetBrains Mono。这些拉丁字体随应用提供，支持可变字重和斜体，使用或预览时按需加载。中文可以选用系统字体或自行导入。「自定义字体 → 管理自定义字体」可导入或移除 TTF、OTF、WOFF 和 WOFF2，单个文件上限为 20 MB。导入的字体保存在应用本地，重开应用或切换稿件后都能使用。移除字体后，文字会按原字体名称查找系统字体，再使用默认回退字体。

也可以直接输入字体名称。「局部样式」可在同一文字层内选取一段文字，设置字体、字号、加粗、颜色或共享颜色样式。点击色块可在取色器切换 HEX、RGBA 或 HSLA，使用屏幕取色和透明度滑杆。填充和描边共用取色器，顶部可切换纯色、渐变和图片，也可选择正片叠底、滤色等混合模式。

渐变支持线性、径向、角度和菱形。打开渐变面板后，可直接在画布拖动渐变手柄和色标，也可在预览条上拖动或输入色标的颜色、位置与不透明度。链形按钮可引用共享颜色。拖动时画布与对应字段同步预览，松手提交一次，取消恢复原值。

图片填充和图片描边支持填满、完整显示和拉伸。可从项目图库或本机选择图片，也可输入项目路径或支持跨域访问的 HTTPS 图片链接。通过链接导入的图片会保存到当前项目，稿件和导出使用项目内的图片。

在填充的色块弹层切换到「着色器」，可从预设的缩略图选择，导入 `.glsl` 文件，或输入项目内的相对路径。使用预设时会将其 GLSL 源码保存到项目。着色器支持 WebGL 的 GLSL ES 1.00 和 3.00 片段着色器。`@resolution` 和 `@time` 自动传入渲染尺寸和时间。参数上方的 `@label`、`@default`、`@range`、`@step` 和 `@color` 注解决定编辑器控件及其默认值。纹理可取项目图片、当前图层背后的内容，或当前图层自身的普通填充和子图层。导出以静态图像保留着色器结果，背景纹理取自导出范围内的图层。

弹性布局支持水平或垂直排列，可在方向旁开启自动换行。九宫格设置对齐，间距下拉提供固定间距、两端对齐和环绕均分。使用内边距标题旁的图标，可在横纵成对和四边独立之间切换。宽高字段各自提供支持的尺寸模式，宽度可加最小值和最大值。切回固定模式时保留当前尺寸。子图层可绝对定位。在弹性画框里拖画形状时会保留绘制坐标，单击插入的形状随布局排列。切回自由布局时保留已排好的位置和尺寸。

选中弹性布局画框后，点击右侧「弹性布局」标题旁的画布调整图标，即可拖动边缘的内边距手柄和图层之间的间距手柄。再次点击图标或按 Esc 退出。内边距沿用面板的成对或四边独立设置。自动分布下，间距拖动从当前实际间距起步，松手保存为固定间距。拖动实时重排，松手只提交一次，拖动中按 Esc 恢复原值。

插入或替换图片时，可在缩略图图库选择项目素材，点「从本机导入」选择文件，或按 Ctrl/Cmd+V 粘贴图片。选中的图片会显示大图预览，确认后才应用到画布。导入的图片在确认时保存在当前项目根目录的 `design-assets` 中，其他稿件也可以复用。在画布上直接粘贴会插入新图层。图片适应方式可选择填满或完整显示。进入裁切后可在画布拖动图片或输入位置百分比。拖动时同步显示裁切，松手提交一次，按 Esc 恢复拖动前的位置。

可以在属性面板把图层或画框创建为主组件。在「设计资源库 → 组件」可以搜索当前稿件和已连接共享库中的组件和变体，拖到画布上松手后创建实例。落点所在的画板能容纳实例时会将它放在画板内，放不下时会在落点创建独立的实例。属性栏和画布空白处的右键菜单也提供「插入组件」。实例的文字和图片可以单独替换或恢复为继承的内容，其余样式继续跟随主组件。实例可以定位到主组件或分离为独立图层。删除主组件前需要分离或移除已有实例。

组件搜索框右侧的图标可切换双列卡片和列表。首次打开显示双列卡片，切换稿件或重启应用后沿用本机上次选择的视图。

主组件可添加并命名加载、禁用等变体。实例可切换变体，并保留对应图层上的文字和图片覆盖。点击侧边工具条的「变量」图标打开变量表。「设计资源库」提供组件、文字样式和共享库。属性栏的变量链接位于对应控件内的右侧，选择「局部值」可解除绑定并保留当前值。

| 变量类型 | 可绑定的属性 |
| --- | --- |
| 颜色 | 填充、描边、阴影、渐变色标、文字局部颜色。变量颜色的不透明度与绑定属性自身的不透明度相乘 |
| 数字 | 自由定位的 X/Y、旋转、固定宽高、最小与最大宽度、间距、内边距、圆角、图层与绘制项透明度、描边宽度、阴影几何、多边形边数、图片裁剪位置、字号、字重、行高和字距。透明度和裁剪百分比使用 0 到 1 的值 |
| 字符串 | 文字内容、字体族 |
| 布尔值 | 隐藏图层、画框裁剪、弹性布局换行 |

在「变量」面板顶部切换集合，点击当前集合名可打开操作菜单，集合列表旁的 `+` 可新建集合。每个集合的变量以名称为行、模式为列并排编辑。点击本地模式的列名可重命名，自建模式也可通过同一个菜单删除。新增模式的单元格默认继承基础值。右上角的「添加变量」可以选择变量类型。颜色变量和手动添加的纯色填充从黑色开始，颜色单元格可编辑 HEX 和不透明度。手动添加描边从 1px 黑色尖角连接开始。文字样式也可引用排版变量。

变量行末的 `…` 菜单可重命名、创建副本、移动到本稿的其他集合或删除。移动时保留已有绑定和模式值，目标集合会补充缺少的模式。

点击变量值旁的链条图标可搜索并引用同类型变量。各模式可以分别选择引用。绑定颜色后，色值位置显示来源变量名。拖动修改来源颜色时，引用单元格、属性栏和画布同步预览。选择「无」会解除当前单元格的引用并保留当前值，随后可直接改色。属性栏的数字链接始终可用，暂无兼容变量时可从菜单打开变量表。选择「局部值」解除链接。在画布上移动图层时，实际改变的位置轴会改用局部值。画板根据每个来源集合选中的模式解析引用。

选中顶层画板，在属性面板的「变量模式」中为本稿和共享库的各个集合分别选模式。例如同一画板可同时选蓝色强调色和深色模式。组件实例继承所在画板的选择，文字覆盖仍以实例为准。引用暂不可用或值与字段不兼容时使用稿件保存的局部值。原型和导出按画板当前选择计算。

在目标稿件打开「设计资源库 → 共享库」，可通过预览卡片浏览同一素材根目录下的源稿件，在卡片底部点击「连接资源库」。连接后可在属性面板的样式列表和「插入组件」中直接引用源资源。源稿件保存后，打开的引用稿件会自动刷新，仍沿用实例自己改过的文字和图片。已连接卡片底部的「取消链接」可把相关实例分离为本地图层，并把直接绑定的共享样式和变量转换为局部值。源稿件移动或改名时，可在共享库重新连接到新路径。

「共享库」旁的「设计资源库」提供 shadcn/ui 和 beUI 的原生组件预设。卡片展示随应用提供的官网首页截图，并跟随应用主题切换。卡片底部提供「连接资源库」与「打开源稿件」。本地稿件可以直接使用随应用提供的源稿，连接保存在设计稿内，移动稿件后仍可使用。存放在项目目录的稿件首次使用时会准备项目内的库源稿，通过相对路径引用，随项目文件一起提供。已有链接继续使用原来连接的源稿。

两套预设源稿存放在 `packages/features/design/src/resources/design-libraries`，由运行时直接导入并随应用构建。每个项目首次使用时从相应源稿创建带独立稿件 ID 的副本。

设计首页和稿件菜单只列普通设计稿。通过「打开源稿件」在当前设计窗体预览库，左侧显示锁定图层。点画布上的组件或左侧的图层，可在右侧查看只读属性。点返回可回到原稿。「组件」可以拖入表单、导航、表格、浮层和提示组件。「文字样式」可以查看共享排版，「变量」可以选择对应库的颜色集合。分离单个实例后可以逐层编辑。

两套库都提供浅色和深色配色，只读源稿跟随应用主题切换。插入稿件后的组件使用所在画板的变量模式，可以在画板的「变量模式」中选择库的 Light 或 Dark。

再次打开或连接预设时，应用会按资源 ID 补齐已有本地或项目副本里的组件、文字样式和颜色。已有实例继续使用原来的库稿 ID 和组件 ID。连接了项目库源稿的设计迁出项目时，可先通过「取消链接」把实例和样式保留为本地内容。

选中按钮或其他图层后，在属性面板的「原型交互」中设置跳转到画板、返回、打开浮层或关闭浮层。跳转和浮层在选定目标画板后保存。选中顶层画板可将其设为稿件的演示起点，也可从属性栏直接播放当前画板。

右上角的播放按钮打开全屏演示，优先从指定起点开始，其次是当前画板，再其次是首张可见画板。演示默认适应窗口。右下角可逐级放大、缩小，点当前比例则可选择适应窗口、适合宽度或 100%。可用左上角的菜单切换画板，也可把鼠标移到两侧边缘，通过出现的箭头切换上一张或下一张画板。菜单里的演示选项提供显示热点、返回和重播。返回会恢复上一次访问的滚动位置，重播回到本次起点顶部。右上角可退出全屏，退出后可接着在原来的画布位置、缩放和选区编辑。

选中图层后，属性面板可复制或保存 HTML 和 HTML + Tailwind，也可导出独立 SVG，或按 1×、2×、3× 导出透明 PNG。HTML 保留弹性布局的填充、适应内容、换行和宽度限制。单独导出一个未旋转或翻转的弹性画框时，页面以窗口宽度排版。SVG 保留矢量轮廓、渐变和裁切，图片内嵌。HTML 和 SVG 会嵌入实际用到的内置字体和允许嵌入的自定义字体，其余字体由打开文件的环境提供。画布和图层树的右键菜单共用复制、粘贴替换、层级、编组、布局、组件、翻转和删除命令。像素网格与吸附偏好保存在本机。包含图片的图层可以在同一素材根目录的设计之间粘贴。

跨稿粘贴会保留图层当前的外观。目标稿已连接相应资源库时，粘贴的图层会继续跟随共享样式和变量更新。把按钮和它跳转的画板一起复制时，粘贴后的按钮会跳转到新画板。

`packages/features/design` 持有版本化文档、typed operation、设计工作区和画布。v7 在原有样式资源上保存多个变量集合，画板模式按稿件与集合定位。绑定与局部值同存，跨稿引用按稿件 ID、项目内路径和资源 ID 定位。画布计算布局前按画板解析变量及其依赖，源稿件刷新独立于目标稿件的写入和撤销历史。v1 到 v6 原有颜色、变量和模式进入默认集合。v8 读取旧稿时将原来隐式的填充与矢量描边连接写入模型，保留旧稿外观。v9 将渐变、图片和混合模式纳入描边。v10 增加位置、旋转、宽度限制、裁剪位置和多边形边数的变量绑定。编辑器可以打开 v1 至 v12 的稿件，更改内容后会以 v12 保存。Yoga 解析布局，Konva 根据计算后的图层变换渲染，画布按视口裁剪渲染范围。两者在打开稿件时按需加载。图片保存为相对素材根目录的引用，并通过工作区文件预览读取。

拖动、旋转和缩放手柄的预览留在 renderer。批量移动、成组和跨画框拖放在松手或执行命令时提交一次。Runtime 通过 workspace adapter 校验变更批次和文件 revision，再原子替换文件。撤销与重做沿用同一提交路径，历史保留在 Runtime 会话内。现有文件监听负责刷新外部修改，磁盘内容变化会使旧撤销历史失效。

图层结构、移动事务、布局和组件交互参考 [Penpot 的图层移动协议](https://github.com/penpot/penpot/blob/develop/common/src/app/common/files/changes.cljc#L231-L253)、[Flex Layout](https://help.penpot.app/user-guide/designing/flexible-layouts/)和[组件](https://help.penpot.app/user-guide/design-systems/components/)。
